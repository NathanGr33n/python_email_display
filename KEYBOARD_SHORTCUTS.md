# ⌨️ Keyboard Shortcuts Reference

Quick reference guide for all keyboard shortcuts in Email Summarizer.

## General

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Refresh emails** | `Ctrl+R` | Fetch new emails from the server |
| **Open settings** | `Ctrl+,` | Open the settings dialog |
| **Quit application** | `Ctrl+Q` | Close the application |
| **Show shortcuts** | `F1` | Display this keyboard shortcuts help |

## Search & Filter

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Focus search** | `Ctrl+F` | Jump to the search bar and select all text |
| **Clear search** | `Escape` | Clear the search (when search bar has focus) |

## Navigation

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Scroll down** | `J` | Scroll the email list down (Vim-style) |
| **Scroll up** | `K` | Scroll the email list up (Vim-style) |

## Multiple Accounts

*These shortcuts are only available when you have 2 or more accounts configured.*

| Action | Shortcut | Description |
|--------|----------|-------------|
| **Next account** | `Ctrl+Tab` | Switch to the next email account |
| **Previous account** | `Ctrl+Shift+Tab` | Switch to the previous email account |

---

## Tips

### Search Mode
- Press `Ctrl+F` to instantly jump to search
- Start typing to filter emails in real-time
- Press `Escape` to clear and exit search

### Vim-Style Navigation
- Use `J` and `K` for quick scrolling without touching the mouse
- Inspired by Gmail and other keyboard-friendly apps

### Quick Account Switching
- `Ctrl+Tab` cycles through accounts like browser tabs
- Great for checking multiple inboxes quickly

### Discover More
- Press `F1` anytime to see all available shortcuts
- Toolbar buttons show their shortcuts in tooltips (hover to see)

## Platform-Specific Notes

### Windows
- All shortcuts use `Ctrl` as the modifier key
- `Ctrl+Q` may conflict with some Windows apps

### macOS (Future)
- Will use `Cmd` instead of `Ctrl` for most shortcuts
- `Cmd+,` is the standard settings shortcut on macOS

### Linux
- Uses `Ctrl` like Windows
- Some desktop environments may override shortcuts

## Accessibility

Keyboard shortcuts improve accessibility by:
- Reducing reliance on mouse/trackpad
- Faster navigation for power users
- Better support for screen readers
- Consistency with other applications

For additional accessibility features, see the main README.md.
